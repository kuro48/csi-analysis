今回の変更の中心は、別実行の診断値を表示する構成から、各比較proof自身の公開値を表示する構成への切り替えです。

各設定・各収録の比較回路
  → 中間値を含む public.json と proof.json を生成
  → 同じ組で verify
  → その public.json を復号して trace.json を作成
  → proof・publicのハッシュとともに波形を表示

発表には02・04・05を使うと、回路への接続から同じ証明との対応まで説明できます。HTMLは元ファイル名・行番号付き。PNGはそのHTMLを描画した画像です。
