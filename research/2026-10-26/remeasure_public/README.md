# 中間値公開を含む比較回路での再測定

## 目的
通常回路のproofと、別実行の診断traceを対応付けたように見せない。今回の比較では各設定の回路自体に中間公開出力を追加し、その回路が生成した各proofのpublic.jsonからだけ波形を取得する。

## 測定対象と集計
- VMD: 6モード数 × 6反復数の36設定＋K3/R4初期中心[8,16,24]候補。
- LS: 1/2/4/8/16/32サブキャリア。
- 各構成で主Raw8収録を各1回証明。代表csi_20260526_034004のみ追加2回、合計10proof/config。
- 一致度集計は8収録。計時は代表収録の3回中央値。繰り返しを独立収録として数えない。
- 元の通常回路の計時、別診断回路のproof/publicは今回の値として再利用しない。

## 証明と図の対応
各run IDにconfig/window/repeat番号を含め、入力・回路・鍵・proof・publicのSHA256を記録。public配列の位置は当該回路schemaとSYMで確認。verify成功したproofのpublicのみを復号・表示し、各波形から元のproof/public/verification keyへ辿れるようにする。

Raw読み込み、VMDのPCA等の前処理、入力選択は回路外。ハッシュによる実験上の対応記録と、回路が証明した範囲は区別する。逆DFT・LSスコア除算は表示側の処理。

## 実行状況
測定中。計時のCPU競合を避け、VMD/LSの重い処理は順番に実行。前回の結果は保管し、今回の成功結果で上書きしない。

現環境はM4 Pro/RAM24GiB。ptau19/21を利用。VMDのK4R32/K5R32/K8R16/K8R32は容量超過見込み。未実行・timeout・OOMを成功扱いせず、理由と完了件数を残す。
