# 2026-10-26 VMD 回路パラメータ比較

ユーザー指定により、今回の報告本編は実測Raw8記録のみ。以下の合成実験は既に取得済みの補足記録として保存するが、本編の図・比較表・結論には使用しない。

## 結論

Raw 直下8記録（各冒頭48秒、独立被験者8人ではない）では、既定 K=3/R=4 の近似VMDと同一入力の Lomb–Scargle 帯域ピークとの差は平均 **10.657 BPM**。K=4/R=4 では **1.108 BPM** まで減少した。ただし K を増やす際に初期中心 bin16 を追加している。K=3 のまま中心を `[8,24,48]` → `[8,16,24]` に変えても、48秒観測部分の LS との差は **10.653 → 1.108 BPM** となった。したがって「モード数を増やせば精度向上」とは断定せず、**初期中心配置が主要な感度要因**と解釈する。

K=3 の R=4→32 は LS 差 **10.657→11.145 BPM** で、反復増加だけでは改善しなかった。既定配置では入力の強い周波数にモードが到達しないケースがある。実データに同期した呼吸ベルト等の参照値がないため、これらは **手法間の一致度であり、人の呼吸数の正解率ではない**。候補配置は同じ8記録を見て評価した探索結果で、未知データでの検証が必要。

## 実験条件

- 主実データ: `../common/windows/csi_*.npz` の8件。sample_data の名前付き2記録は主集計に含めない。
- 元の不均一時刻を使って48秒を100 Hzへ補間し、共通SNR選択/PCA/前処理、2 Hzへ低減。96点の観測波形にゼロ32点を追加し、平均除去・±100整数化して既存回路の128点入力にする。来歴は `../common/manifest.json`。
- このため64秒の生波形を観測した実験ではない。既存運用の固定100 Hz仮定そのものを再現した実験でもない。
- K=`1,2,3,4,5,8`、R=`1,2,4,8,16,32`、計36条件。
- 初期中心は入れ子列 `[8,24,48,16,32,56,40,4]` の先頭 K 個。K=3の既定配置を保存しつつ追加する設計なので、モード数と配置の効果は交絡する。
- 同一128点・同一整数入力に対し、既存回路と等価な整数更新式を評価。DFT三角表scale1000、正周波数bin1..63、符号付き0方向除算、整数中心、全モード全ビン最大ピークを選ぶ。
- 比較LS: SciPyの同一入力 `.05..99 Hz, step=.00025 Hz` の周波数探索。帯域優先結果は `.1..22/60 Hz`。このLSは他担当のCSI入力証明回路スイープと入力範囲が異なるため、両者の数値を直接同列に置かない。
- 通常VMD: vmdpy 0.2、K5/alpha2000/tau0/DC0/init1/tol1e-7。同一2 Hz波形で条件をそろえた比較であり、既存100 Hz VMDパイプラインの性能再現ではない。

## 対照と診断

- 直接合成波形45件: 9/12/15/18/21 BPM × clean/noise/strong_interferer × 3seed。noise SD0.35、強い干渉は0.7 Hz振幅1.6、目標振幅1。known targetに対する誤差を実データと分けて評価。
- 共通合成CSI6件: `../common/synthetic`、9/12/18 BPM × 2雑音条件。同じ生成CSIを起点とするが、VMDはPC+128点padding、LS担当はraw64点・帯域選択のため、最終入力・前処理は異なる。手法全体の比較として解釈する。
- 45直接合成の既定K3R4 MAE: clean **0.263 BPM**、noise **3.050 BPM**、strong_interferer **18.225 BPM**。全周波数最大を選ぶ仕様では強い帯域外干渉を選びうる。単に反復を増やすだけで解決する問題ではない。
- 初期配置6種類、padding4種類(zero/reflect/edge/wrap)、R4/32の診断を `diagnostics*.json/csv` に保存。反射paddingを使うだけでは既定配置の不一致を解消しなかった。
- DFT単独の実データLS差は0.263 BPM、通常VMD全ピーク選択0.967 BPM、通常VMD帯域優先2.490 BPM。量子化や入力だけではなく、近似更新・初期化・モード選択の影響を切り分ける必要がある。

## 回路検証と時間の意味

`circuits/` に本番ソースを変更せずK1R1/K3R4/K5R8/候補K3R4を生成。`build/` にそのWASM/R1CS/SYMを保存。初期1窓では全最終モード係数・中心・公開判定値がPython整数参照と完全一致した。全8窓の追加検証は `all_windows_circuit_validation.json` を参照（32件）。これは witness 生成・回路内assertの実行であり、Groth16証明生成・検証の完了を意味しない。

## 再実行

主手順は `--real-only` を指定し、直接合成45件と共通合成CSI6件の両方を除外する。`--output-dir` に別フォルダを指定すれば既存全条件の結果を上書きしない。オプションなしの従来動作（全条件）は互換性のため維持。

必要パッケージ: numpy/scipy/vmdpy、Node、`zkp/node_modules/.bin/circom2`。本実行では `/usr/bin/python3` と vmdpy 0.2 を使用。

```bash
python3 zkp/experiments/2026-10-26/vmd/test_model.py
python3 zkp/experiments/2026-10-26/vmd/run_sweep.py --real-only --output-dir zkp/experiments/2026-10-26/vmd/raw_only
```

`test_model.py` は既存参照実装との11入力の全係数一致、3既知tone、入力拒否の3テストを実行。生成回路は実験用で、本番統合・trusted setup・鍵更新は行わない。

スクリーンショット推奨: `model.py:23` の整数モード更新〜最大ピーク選択（23–37行）、同ファイル7行の初期中心、`generate_variant.py` の既定回路からのパラメータ置換。結果の図は親レポート側に保存。

## 初期中心候補の合成データ検証

`validate_candidate.py` / `candidate_validation.json` はK3/R4を固定し、既定 `[8,24,48]` と候補 `[8,16,24]` を同じ51合成ケースで比較する。

| 条件 | n | 既定GT MAE (BPM) | 候補GT MAE (BPM) | 候補で悪化した数 |
|---|---:|---:|---:|---:|
| clean | 15 | 0.2625 | 0.2500 | 0 |
| noise | 15 | 3.0500 | 0.2625 | 0 |
| strong_interferer | 15 | 18.2250 | 0.2625 | 0 |
| 共通合成CSI | 6 | 0.3125 | 0.5000 | 2 |

直接合成では改善したが、共通合成CSIでは6件中2件が悪化した（どちらの配置も全6件は誤差1 BPM以内）。よって候補配置は一律に優れるわけではない。候補は低周波帯に中心を寄せており、この合成群の呼吸周波数・干渉周波数条件に適合している可能性がある。帯域外目標や未知の混合信号、同期生理GTによる追加評価が必要。全51件の単純平均は各条件の比率に依存するため、条件別値を主結果とする。

```bash
python3 zkp/experiments/2026-10-26/vmd/validate_candidate.py
```

## 広い周波数範囲の純正弦診断

`validate_wideband.py` / `wideband_validation.json` では、3/6/9/12/18/21/24/30/42/51 BPMの純正弦を64秒・2 Hz・振幅80で生成し、K3/R4の既定/候補配置を比較した。各ケースの注入正弦そのものを正解とし、高周波成分をあらかじめ干渉とは扱わない。

| 注入BPM | 既定出力BPM | 候補出力BPM | DFT最大BPM |
|---:|---:|---:|---:|
| 3 | 2.8125 | 2.8125 | 2.8125 |
| 6 | 5.6250 | 5.6250 | 5.6250 |
| 9 | 8.4375 | 9.3750 | 9.3750 |
| 12 | 12.1875 | 12.1875 | 12.1875 |
| 18 | 17.8125 | 17.8125 | 17.8125 |
| 21 | 20.6250 | 20.6250 | 20.6250 |
| 24 | 23.4375 | 23.4375 | 24.3750 |
| 30 | 30.0000 | 30.0000 | 30.0000 |
| 42 | 42.1875 | 22.5000 | 42.1875 |
| 51 | 47.8125 | 25.3125 | 50.6250 |

**候補は高い周波数の目標成分を捉えにくくなる。** 42 BPM純正弦で候補出力は22.5 BPMへ大きくずれた。先の合成実験では同じ0.7 Hz（42 BPM）成分を「干渉」と定義したため、これを選ばないことがGT誤差改善となっていた。しかし、その成分が真の呼吸目標か干渉かを、この計算だけで判別できるわけではない。したがって単純な「干渉耐性向上」や広帯域での精度改善とは述べず、**低周波側への選択傾向と高周波目標の取りこぼしの両面**を報告する。既定も51 BPMを47.8125 BPMと推定しており、既定配置自体も広帯域精度を保証しない。

```bash
python3 zkp/experiments/2026-10-26/vmd/validate_wideband.py
```
